# Contribuer à Optical Lab
1. Ouvrir une issue avec le contexte, l'acceptation et le sprint.
2. Créer une branche dédiée à partir de `main` (`feat/S1-material-import`, `fix/...`).
3. Conserver le PRD et la démarche scientifique comme références ; proposer un ADR pour une modification de modèle ou de stack.
4. Écrire des tests pertinents ; consigner les références et hypothèses.
5. Ouvrir une PR avec liste des changements, commandes de tests, captures d'UI si utile et points non validés.
6. Fusion après revue et contrôles verts. Éviter les commits directement sur `main` pendant l'implémentation.

Les données sous droits, clés API et gros fichiers bruts ne doivent pas être ajoutés au dépôt.
