# Gouvernance et licences des données
1. **RefractiveIndex.INFO** : référencer l'URL officielle, l'identifiant de commit du dépôt, le chemin YAML, auteurs, références, DOI et intervalle spectral.
2. **Touloukian** : ne pas déposer scans, planches ni chapitres protégés dans un dépôt public sans autorisation. Documenter volume, édition, pages et conditions ; comparer seulement les grandeurs physiquement équivalentes.
3. **EKHI** : vérifier licence/conditions de redistribution du jeu exploité. Préserver origine des données, auteurs et transformations.
4. **Sources laser/soleil/lampe** : conserver la référence exacte de chaque spectre et les unités (densité spectrale, puissance/irradiance).
5. **Raw data** : hors Git par défaut ; fixtures libres et limitées dans le dépôt ; aucun secret/tokens dans Git.
6. **Versionnement** : hash des sources, date d'import, version du script, transformations déclarées et exports reproductibles.
7. **Licence du code** : aucune licence explicite choisie à ce stade. Décider avant redistribution ou contributions externes.
